# Heapsort

Реалізація алгоритму сортування купою (Heapsort) на Python з підрахунком порівнянь і присвоювань, трасуванням кроків та тестами.

## Файли

- `heap_sort.py` — функції `sink`, `heapsort`, підрахунок операцій, трасування
- `tests.py` — випадкові тести, перевірка стійкості, заміри

## Запуск

```
python heap_sort.py
python tests.py
```
